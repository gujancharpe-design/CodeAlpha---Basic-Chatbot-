🤖 Basic Chatbot

A simple Python-based chatbot that interacts with users through text messages. It responds to basic questions and greetings using predefined responses, making it a beginner-friendly project to understand chatbot functionality.

✨ Features
Interactive Conversation: Allows users to communicate with the chatbot through text input.
Predefined Responses: Replies to common greetings and simple questions.
Input Handling: Accepts and processes user messages.
User-Friendly: Easy to use and beginner-friendly interface.
Exit Option: Allows users to end the conversation whenever they want.

🛠️ Built With

Language: Python 3.x
Libraries: Standard Library

🚀 Getting Started

Prerequisites

Make sure Python is installed on your system. You can check the version by running:

python --version

Run the Program

python basic_chatbot.py
